Data Backup

Save a copy of your ledger, restore it, or export a spreadsheet-friendly copy for Excel. Your account, password and login sessions are never included in a backup.

JSON backup Restorable

Downloads your complete ledger — every inflow, outflow, loan, contract and the budget, including entries you've deleted — as one .json file. This is the file to keep for a safe restore.

Off by default: a backup you email or store elsewhere then carries your family's contact details. Leave this unchecked unless you specifically need them in the file — the budget and schedule times are always included either way, and restoring a backup without contacts leaves any already saved on this device untouched.

Import / Restore Replaces data

Restores a Plannr JSON backup, replacing all current ledger data with the file's contents. Your current data is automatically saved to a snapshot first.

Warning: this replaces everything in the ledger and can't be undone from inside the app.

Encrypted full backup Restorable

Downloads the entire database — every table, exactly as stored — encrypted with a passphrase you choose, as one .db.enc file. Cross-compatible with the encrypted snapshots the desktop install can make.

Anyone with this file still needs the passphrase to read it — but anyone with BOTH can read everything, including anything the JSON backup leaves out by default. Store the passphrase somewhere separate from the file.

Restore from encrypted backup Replaces data

Restores a Plannr encrypted (.db.enc) backup, replacing everything currently stored with the file's contents.

Warning: this replaces the entire database and can't be undone from inside the app.

CSV for Excel Export only

Downloads a set of clearly-named .csv files (one per table) with amounts in rupees and ledger codes shown with their names — easy to open, read and print in Excel.

CSV is for viewing/printing in Excel and cannot be imported back — use JSON to restore. CSV shows your live entries only (deleted rows are left out; the JSON backup keeps them).

Recycle Bin Restore / delete

Everything you've deleted across Plannr is kept here. Restore returns a row to its page and back into the Overview totals. Delete permanently removes it for good — that one, unlike every other delete in the app, cannot be undone.
